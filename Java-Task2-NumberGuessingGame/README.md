# Number Guessing Game

## Objective
A console-based Java application where the computer generates a random number and the player has to guess it within a limited number of attempts.

## Features
- Random number generation
- Three difficulty levels (Easy, Medium, Hard)
- Too High / Too Low hints
- Maximum attempt limit
- Play Again option
- Round Summary

## Technologies Used
- Java
- Scanner Class
- Random Class

## How to Run

Compile:

```bash
javac Main.java
```

Run:

```bash
java Main
```
